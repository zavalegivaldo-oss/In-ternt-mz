# Meu Despertador

Aplicação web simples em português para ver as horas e criar alarmes. Os alarmes são guardados no armazenamento local do navegador; é possível ativar/desativar cada um, definir repetição diária e testar o som. A página pode ser instalada como PWA e fica disponível offline depois de ser aberta pelo menos uma vez num navegador compatível.

## Limitação importante

O alarme toca enquanto a página está aberta e o dispositivo está ligado. Navegadores não garantem que um alarme local toque quando a página foi fechada, o navegador foi encerrado ou o dispositivo está desligado. A permissão de notificações pode mostrar um aviso quando o app está aberto, mas não substitui um alarme nativo do sistema.

Para tocar com o app fechado ou com o dispositivo bloqueado de forma confiável, é necessária uma aplicação nativa e suporte específico de alarmes/notificações do sistema operativo.
